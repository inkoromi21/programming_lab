# Лабораторная работа: Обработка массивов

## Автор
Воробьев Семен (Вариант 3)

## Цель
Научиться работать с массивами.

## Описание
Программа принимает квадратную матрицу произвольного размера, считает сумму и количество элементов под главной диагональю и выводит.

## Исходные данные
Квадратная матрица произвольного размера.

## Ожидаемые результаты
Программа выводит:
Матрицу,
количество элементов под главной диагональю,
сумму элементов под главной диагональю.
