# Лабораторная работа: Циклы с ветвлением

## Автор
Воробьев Семен (Вариант 3)

## Цель
Освоение базового синтаксиса C++ и математических вычислений на примере расчета периода колебаний маятника.

## Описание
Программа позволяет посчитать и вывести число Рейнольдса и коэфицент сопротивления.

## Исходные данные
- Диаметр трубы: 19.1 мм
- Скорость: 1, 2, 5, 10, 20, 50, 100 м/с
- Вязкость жидкости: 0.009 см²/с

## Ожидаемые результаты
Программа выводит 6 значений R и 6 значений A, зависящий от значений j.
