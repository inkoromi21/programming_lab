# Лабораторная работа: работа с файлами

## Автор
Воробьев Семен (Вариант 3)

## Цель
Научиться работать с файлами на языке C++

## Описание
программа находит список книг искомого автора и общую их стоимость, а также находит старейшую книгу.

## Исходные данные
-файл с списком книг
-фамилия нужного автора

## Ожидаемые результаты
Программа выводит:
-список книг автора
-старейшую книгу и год ее выпуска
-стоимость всех книг автора
