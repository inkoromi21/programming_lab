# Лабораторная работа: Перевод арабских чисел в римские и наоборот

## Автор
Воробьев Семен (Вариант 3)

## Цель
Сделать переводчик из арабских чисел в римские и наоборот.

## Описание
Программа переводит из арабских чисел в римские и наоборот.

## Исходные данные
- Число, написанное либо арабскими, либо римскими цифрами

## Ожидаемые результаты
Программа выводит либо число из арабских чисел, либо из римских.
