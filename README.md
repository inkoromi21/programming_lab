# Лабораторная работа: Расчет повторений

## Автор
Воробьев Семен

## Цель
Освоение синтаксиса С++

## Описание
Программа считает количество повторений одиночных букв и комбинаций двух букв

## Исходные данные
-Текст

## Ожидаемые результаты
Программа выводит 2 списка:
-список повторений одиночных букв
-список повторения комбинаций двух букв
