# Лабораторная работа: Использование процедур и функций

## Автор
Воробьев Семен (Вариант 3)

## Цель
Освоение процедур и функций в С++.

## Описание
Программа находит сумму элементов массива G, которые меньше b, а также сумму элементов массива V, которые меньше b.

## Исходные данные
- введенное пользователем b.
- Введенная матрица G.
- Введенная матрица V.

## Ожидаемые результаты
Сумма элементов массива G, которые меньше b, и сумма элементов массива V, которые меньше b.
